3). High-Level VS low-Level Languages

>> High-Level Language
	A high-level language is closer to human languages and easier to understand.

Example:

Python
C
C++
C#
Java etc.

Benefits:

>> Easy Syntax  English
>> Faster Development
>> Easy Debugging --> Bug --> Debug

Example:

calc.py
------------------
a = 10
b = 20
print(a+b) = 30
---------------------------------------------------------------------------------
calc.c 

# include <stdio.h>

int main(){
	var int a;
	a = 10;
	var int b;
	b = 20;
	var int c;
	c = a+b;
	printf("%d",c); 
	return 0
};

calc.exe  --> Object file

file: machine code  --> 30
----------------------------------------------------------------------------------------------------

Low-Level Language
--------------------------

Low-Level languages are closer to machine and difficult for humans.

-------------------------------------------------------------------------------
Example:-

Assembly Language

Machine Code(0,1)
---------------------------------------------------------------------------------

Benefits:

>> Very Fast Execution
>> Direct Hardware control
------------------------------------------------------------------------------------------

High-level language are like English, Low-Level language are like binary signals.

4). Compiler vs Interpreter
--------------------------------------------------------------------------------------------------

✅ Compiler
-----------------

A compiler translate the entire code at once into machine code.
------------------------------------------------------------------------------------

Example:

C
C++
Java(Java Uses both compiler + Interpreter concept)


Characteristics:

>> Faster Execution
>> Errors shown after full compilation
-------------------------------------------------------------------------------------------


✅ Interpreter

------------------------

An Interpreter translate the program line by line.

Example:

Python
JavaScript
Ruby
Perl
LISP
ProLog
etc.


Characteristics

>> Easy Debugging
>> Slower than compiled languages
>> Execute directly
--------------------------------------------------------------------------------------------------

Feature		| 	Compiler	| 	Interpreter	|
---------------------------------------------------------------------------
Translation	| Whole at once		| Line by Line
--------------------------------------------------------------------------
Execution Speed	|Fast			| Slower than compiler
-------------------------------------------------------------------------------
Error Display	| After Compilation	| Immediately
-----------------------------------------------------------------------------
Example		| C, C++		| Python, Ruby, JavaScript	
-------------------------------------------------------------------------------------------
