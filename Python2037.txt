4). Compiler vs Interpreter
--------------------------------------------------------------------------------------------------

✅ Compiler
-----------------

A compiler translate the entire code at once into machine code.
------------------------------------------------------------------------------------

Example:

C
C++
Java(Java Uses both compiler + Interpreter concept)


Characteristics:

>> Faster Execution
>> Errors shown after full compilation
-------------------------------------------------------------------------------------------


✅ Interpreter

------------------------

An Interpreter translate the program line by line.

Example:

Python
JavaScript
Ruby
Perl
LISP
ProLog
etc.


Characteristics

>> Easy Debugging
>> Slower than compiled languages
>> Execute directly
--------------------------------------------------------------------------------------------------

Feature		| 	Compiler	| 	Interpreter	|
---------------------------------------------------------------------------
Translation	| Whole at once		| Line by Line
--------------------------------------------------------------------------
Execution Speed	|Fast			| Slower than compiler
-------------------------------------------------------------------------------
Error Display	| After Compilation	| Immediately
-----------------------------------------------------------------------------
Example		| C, C++		| Python, Ruby, JavaScript	
-------------------------------------------------------------------------------------------

✅ Python Installation(Windows).
---------------------------------------
Step 1: Download Python
1. Open Browser
2. Search Python official website
3. Open: python.org
4. click Downloads
5. Download Latest version.

-----------------------------------
Step:2: Run Setup File

1.Open downloaded .exe file
2. IMPORTANT: Tick the checkbox
	✅ Add Python to PATH
3. Clin on Install Now

📌 If you forget to tick "Add Python to PATH", Python will not run in CMD properly.

---------------------------------------------------
Step 3: Verify Installation
1.Open Command Prompt(CMD)
2. Type: python --version
-----------------------------------
Step 4 : check pip installation

Pip is used to install libraries
